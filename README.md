# Rodrigo Pereira Rodrigues - Portfolio

Este repositório contém meu portfólio pessoal de desenvolvimento web.

O objetivo deste projeto é apresentar meus estudos em programação, desenvolvimento de aplicações e tecnologia.

## Tecnologias utilizadas

- JavaScript
- React
- Vite
- HTML
- CSS
- Git

## Sobre o projeto

Este portfólio foi desenvolvido para reunir projetos e demonstrar minhas habilidades em desenvolvimento web e tecnologia.

Ao longo do tempo, novos projetos e melhorias serão adicionados.

## Como rodar o projeto

Clone o repositório:

git clone https://github.com/rodriguesr-data/portfolio-rodrigo.git

Entre na pasta do projeto:

cd portfolio-rodrigo

Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:

npm run dev

Depois acesse no navegador:

http://localhost:5173
